隱私權政策

Realtime Multilingual Traditional Chinese Subtitles（Realtime Subtitles）
最後更新：2026 年 11 月 17 日

本擴充功能在使用者主動啟動後，擷取所選分頁的音訊，透過使用者設定的語音辨識與翻譯服務，在網頁上顯示原文及繁體中文字幕。本政策說明擴充功能如何處理資料。

一、處理的資料與用途

  • 分頁音訊：按下 Start Capture 後，擷取目標分頁播放的音訊，傳送至所選語音辨識服務以產生字幕；本功能不擷取麥克風。按下 Stop Capture 後會停止擷取並關閉相關連線。
  • 辨識文字與翻譯：將辨識出的文字傳送至所選翻譯服務，並將原文和譯文呈現在目標網頁。
  • API 憑證：處理使用者輸入的 API key，供所選服務驗證請求使用。憑證不提供給網頁字幕內容腳本讀取。
  • 偏好設定：保存模型、服務端點、憑證保存模式、字幕字體、位置、寬度及背景透明度等設定。
  • 分頁與執行狀態：在本機使用分頁識別及必要的網頁資訊以定位字幕顯示位置、處理頁面切換及結束擷取；不建立瀏覽歷史資料庫。

二、第三方服務與資料傳送

目前版本由擴充功能直接連線至使用者選擇的服務，沒有由開發者另設的字幕資料中繼伺服器。

  • Deepgram：選用 Deepgram 語音辨識時，音訊及辨識所需設定會傳送至 Deepgram。請參閱 Deepgram 隱私權政策。
  • Google Gemini：選用 Gemini 語音辨識時會傳送音訊；選用 Gemini 翻譯時會傳送辨識文字。請參閱 Google 隱私權政策及 Gemini API 服務條款。
  • 自訂翻譯 API：選用自訂 OpenAI 相容服務時，辨識文字、翻譯指令及必要的模型設定會傳送至使用者填寫的端點；若設定 API key，也會用於該端點的驗證。

API key 會用於對應服務的驗證。各服務也可能依網路連線取得 IP 位址及請求中繼資料。服務端的保存期限、資料使用與刪除方式，依服務供應商的政策、方案及帳號設定而定；開發者無法代替使用者控制或刪除服務端資料。

「測試連線」會實際向選定端點發出測試請求，可能包含短測試文字或服務驗證資訊，並可能產生 API 費用。自訂端點請優先使用 HTTPS；連至遠端 HTTP 端點時，文字與憑證可能以未加密方式傳輸，請勿向不可信任的端點提供資料。

三、本機保存、安全與保存期限

  • 「僅本次瀏覽器工作階段」的憑證存於 chrome.storage.session，瀏覽器工作階段結束後不再保留；「記住此裝置」的憑證及偏好設定存於 chrome.storage.local。
  • 憑證不透過 chrome.storage.sync 同步至其他 Chrome 裝置。憑證儲存區限制為擴充功能可信任環境存取，但 Chrome 儲存區並非本擴充功能另行加密的金鑰保險箱。
  • 音訊於擷取期間作串流處理及短暫緩衝，目前不提供音訊錄檔保存。字幕及請求資料於執行期間處理，不建立持久的字幕歷史資料庫；停止後畫面可能保留字幕，直到清除字幕或頁面關閉。
  • 開啟 Debug 模式時，本機開發者主控台可能顯示原文、譯文、連線狀態及錯誤資訊。請勿將含敏感內容的除錯記錄公開分享。

四、使用者控制與刪除

可隨時停止擷取、清除畫面字幕，並在 API 設定中移除各服務的 key。偏好設定會保存至變更、清除擴充功能資料或解除安裝為止。可在 Chrome 擴充功能設定中撤銷網站存取權限。解除安裝會移除該 Chrome 設定檔中的擴充功能本機儲存資料；已傳送至第三方的資料，請依供應商流程管理或申請刪除。若 key 可能外洩，請向供應商撤銷或更換。

五、資料用途限制

本擴充功能對使用者資料的使用與傳送遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。資料僅用於提供或改善所述即時字幕功能，不販售使用者資料、不作個人化廣告、不用於信用評等或貸款決策，也不傳送至與字幕功能無關的分析或廣告服務。為提供字幕而向所選語音辨識及翻譯服務傳送必要資料，屬本功能的一部分。

本政策說明擴充功能的行為；第三方服務對所接收資料的處理仍受其條款與隱私權政策約束。

六、政策更新與聯絡方式
